# Agentic Design Shopping Skill

Execute an autonomous "shopping" mission to find the best design assets across 11 integrated high-signal sources.

## When to Use
- When the user asks for "inspiration", "ideas", "how to design X", or "show me examples of Y".
- At the start of a new design project or feature.

## Key Actions
1.  **Global Search:** Use `search_inspiration` to get a broad overview.
2.  **Brand Benchmarking:** Use `browse_brand_designs` to see how industry leaders (Apple, Stripe, Airbnb) solve similar problems.
3.  **Motion & UX Deep Dive:** Use `browse_godly` for interactions and `browse_mobbin` for mobile flows.
4.  **Synthesis:** Combine all findings into a `get_design_brief`.

## Directives
- **Multi-Source Priority:** Never rely on just one source. Always cross-reference at least 3 sources (e.g., Awwwards for visual, Mobbin for UX, a Brand for system logic).
- **Technical Extract:** Don't just describe visuals; extract specific hex codes, font families, and spacing rules.
